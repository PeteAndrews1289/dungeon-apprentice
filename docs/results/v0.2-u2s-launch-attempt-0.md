# U2-S Launch Attempt 0: Safe Pre-Action Infrastructure Failure

## Outcome

U2-S attempt 0 is terminal `operationally_incomplete` evidence. It did not test the learner.

The launcher successfully authenticated the frozen source, tag, qualification, parent, storage
volume, and dashboard. It then opened the control arm. Before the first action, the trainer's
storage audit refused to continue because the arm-specific media directory had not been created.
The launcher recorded the arm as crashed and the four-arm non-resume rule closed the cohort.

## Root cause

The cohort contract gave every arm both a scientific directory and a media directory. The launcher
created the shared scientific and media roots, but only the trainer created the arm's scientific
directory. Its first call to the fail-closed storage audit therefore found:

`FileNotFoundError: storage directory does not exist: /Volumes/T7 Developer/DungeonApprentice/u2s-ablation-media-20260723/control`

This refusal was correct. Automatically weakening the storage check or creating the directory from
inside a partially initialized trainer would have hidden an operational contract violation.

## r1 correction

The replacement changes no scientific variable. After the manifest durably opens an arm and before
the supervisor starts its trainer, the launcher now:

1. refuses an existing or symlinked arm media target;
2. creates the exact directory non-recursively with mode `0755`; and
3. validates its entire ancestor chain beneath the fixed storage root.

Putting this step after manifest start means a directory-creation or path-validation failure is
itself recorded as a crashed active arm. Putting it before trainer spawn ensures the storage guard
can pass without relaxing its safety boundary.

The replacement receives a new source commit, annotated tag, qualification, cohort ID, scientific
root, and media root. All four arms restart from the confirmed U1 parent. No attempt-0 policy state
exists to reuse.

## Narrative significance

This is a useful negative result in the project's engineering story: the safety system stopped a
bad launch before it could masquerade as machine-learning evidence. The repair is intentionally
small and auditable, while the non-resume rule forces the comparison to remain fair.
