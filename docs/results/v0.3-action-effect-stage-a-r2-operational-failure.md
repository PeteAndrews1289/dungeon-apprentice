## Outcome

the complete sham arm. The sham reached exactly 1,048,576 fresh child actions and emitted all 32
scheduled exams. Its trainer closed normally with a complete report and terminal checkpoint.

The cohort then stopped fail-closed while the manifest authenticated that completed arm. The
trainer and qualifier used the frozen U2-S first-rollout digest profile, whose canonical JSON bytes
end with one line-feed byte. The manifest recomputed the same identity with its generic canonical
JSON helper, which omitted that byte. Those two byte contracts produced different SHA-256 values,
so the manifest rejected authentic evidence as unauthenticated.

The action-effect arm never received an attempt or directory. Therefore r2 did **not** perform the
matched comparison and supplies no evidence for or against the action-effect architecture.
